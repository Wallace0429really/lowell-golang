## 🚀 Quick Start

### Windows
1. Download `lowell-stable-windows.zip`.
2. Extract the folder.
3. Open the folder and double-click `lowell.exe` to see the welcome message.
4. To use it anywhere, add the folder path to your System Environment Variables (PATH).
5. Then, refresh your powershell (Basically opening a new tab), and type in: "lowell repl" to start.
